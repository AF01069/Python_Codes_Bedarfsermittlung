# Contributing

Vielen Dank für dein Interesse am Projekt!

## Grundsätze
- Bitte respektiere Datenlizenzen und Datenschutzvorgaben.
- Keine sensiblen Daten committen (`data/`, `out/`, `cache/`, `work/` sind ausgeschlossen).

## Setup (Kurz)
1) Python-Umgebung in `venv/` verwenden.
2) Datensätze gemäß `README.md` in `data/` ablegen.

## Beiträge
- Fork erstellen oder Branch anlegen.
- Änderungen mit klaren Commit-Nachrichten.
- Pull Request mit kurzer Beschreibung und Testhinweis.

## Tests
Wenn möglich, führe einen kurzen Lauf aus:
```powershell
.\venv\Scripts\python.exe main.py
```
