# Datasets and data files (project overview)

This document lists input datasets, generated caches, and outputs used by the project.
It includes code usage references and known license/terms. Unknown items are marked as TODO.

## Inputs (authoritative / provided by data owners)

### 1) HK-DE Adressen (amtliche Hauskoordinaten Deutschland)
- Paths:
  - data/Adressen/hk_sn_adressen_20250918.txt
  - data/Adressen/Datenformatbeschreibung_HK-DE_V_5.2.pdf
- Used by code:
  - main.py (HK_PATH)
  - kwp_bedarfskennwerte/utils/addresses_hk.py (auto-detection + parser)
  - kwp_bedarfskennwerte/workflows/ap1_enrich.py (_enrich_with_hk)
- Purpose:
  - Enrich buildings with postal address attributes (PLZ, street, etc.).
- License/terms (summary):
  - Restricted product; usage depends on V GeoBund / V GeoLaender agreements; source attribution required.
  - See official HK-DE product page and license PDFs from BKG/GeoBasis-DE.
- License/terms links:
  - https://gdz.bkg.bund.de/index.php/default/amtliche-hauskoordinaten-deutschland-hk-de.html
  - https://sg.geodatenzentrum.de/web_public/gdz/lizenz/deu/nutzungsbedingungen_hk-de.pdf

## Derived outputs (project results; stored under out/)

These outputs are generated by the pipelines and should inherit licensing constraints from inputs.

- out/ghs_obat/ghs_obat_clip.gpkg
  - Generated by: GhsObatSource.load (clip of GHS-OBAT to project bbox)
- out/zensus/ap1_buildings_enriched_zensus.gpkg / .csv
  - Generated by: ap1_enrich (_enrich_with_zensus)
- out/hk_addresses/ap1_buildings_enriched_hk.gpkg / .csv
  - Generated by: ap1_enrich (_enrich_with_hk)
- out/ap1/geometry_analysis/*_geomstats_attributes.csv
  - Generated by: ap1 pipeline geometry analysis
- out/ap2/*.gpkg
  - Generated by: ap2 pipeline (typed, heat, cold, refurbishment)
